Política de Privacidade — Hermes Video Uploader

Última atualização: 18 de novembro de 2026

Quem usa

O Hermes Video Uploader é uma ferramenta pessoal, usada apenas pelo seu autor (Gabriel, gabrielv.developer@gmail.com) para publicar vídeos no próprio canal do YouTube. Não é distribuída nem oferecida a outros usuários.

Dados acessados

Com a autorização do titular da conta, por meio do OAuth do Google, o aplicativo usa a YouTube Data API v3 para:

  • enviar vídeos, títulos, descrições, tags, legendas e miniaturas para o canal do próprio titular;
  • ler o nome e as estatísticas básicas do canal autorizado, para confirmar que o canal está correto.

Nenhum dado de outros usuários do YouTube ou do Google é acessado.

Armazenamento

O token de acesso fica salvo só no computador do autor e nunca é enviado a servidores de terceiros. O aplicativo não tem servidor próprio, banco de dados remoto, publicidade nem análise de uso. Ele não vende, compartilha nem transfere dados.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O aplicativo usa os Serviços de API do YouTube e, portanto, segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Basta apagar o arquivo de token local para remover todos os dados guardados pelo aplicativo.
